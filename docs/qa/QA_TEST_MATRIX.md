# SymptomMate MVP 验收测试矩阵

测试目标：确认 20 个症状在低风险/普通、黄灯、红线、特殊人群和边界输入下，都能给出清晰、安全、可解释的就医参考。

## 通用验收标准

- 首页展示 20 个症状入口：胸痛、头痛、腹痛、咳嗽、发热、腹泻、头晕、背痛、皮疹、呕吐、鼻塞、咽痛、耳痛、尿痛、月经异常、眼红、乏力、心慌、失眠、关节痛。
- 每个症状进入后都有 5 轮专属追问。
- 每个追问展示问题目的解释。
- 红线选项触发后进入全屏红线预警页，且不提供继续自查入口。
- 结果页展示：行动建议、为什么这样建议、安全说明、推荐科室、下一步建议、排查方向、升级处理信号、反馈按钮。
- 历史记录页能看到本次自查记录。
- 文案不出现诊断、治疗、处方结论。

## 症状用例表

说明：低风险/普通路径不等于一定绿灯。胸痛、头晕等高敏感症状即使未触发红线，也可以因产品安全策略返回黄灯。

| 症状 | 低风险/普通路径 | 黄灯/保守路径 | 红线路径 | 特殊人群路径 | 预期科室 |
|---|---|---|---|---|---|
| 胸痛 | 隐隐痛/刺痛 → 没有放射 → 无明显异常 → 少于10分钟 → 不会；预期黄灯，因为胸痛默认偏保守 | 胸闷压迫感 → 没有 → 无明显异常 → 10-30分钟 → 活动后加重 | 压榨样疼痛 | 不适用，胸痛默认偏保守 | 心内科 |
| 头痛 | 慢慢加重 → 0-3分 → 没有 → 无明显异常 → 少于6小时 | 反复发作 → 7-8分 → 没有 → 呕吐 → 1-3天 | 突然爆发样剧痛 | 老人/基础病补测时应偏保守 | 神经内科 |
| 腹痛 | 上腹部 → 0-3分 → 无明显异常 → 少于6小时 → 基本可以 | 右下腹 → 7-8分 → 发热或呕吐 → 6-24小时 → 需要卧床休息 | 持续加重/按压明显痛 | 孕产妇腹痛应人工判为高关注 | 消化内科 |
| 咳嗽 | 少于3天 → 没有 → 没有 → 无痰或少痰 → 成年人 | 超过14天 → 轻微胸闷 → 高热 → 黄绿痰 → 成年人 | 明显呼吸困难 | 儿童/老人咳嗽伴发热应偏保守 | 呼吸内科 |
| 发热 | 37.3-38℃ → 少于6小时 → 精神尚可 → 无明显异常 → 成年人 | 39-40℃ → 1-3天 → 明显乏力 → 皮疹 → 成年人 | 超过40℃ | 38-39℃ → 1-3天 → 精神尚可 → 无明显异常 → 儿童，预期黄灯 | 全科 |
| 腹泻 | 1-3次 → 没有 → 没有 → 少于24小时 → 成年人 | 7次以上 → 少量黏液 → 尿量减少 → 1-3天 → 成年人 | 便血/黑便 | 老人/儿童腹泻应偏保守 | 消化内科 |

| 背痛 | 久坐/劳累后 → 没有 → 0-3分 → 少于24小时 → 没有 | 搬重物后 → 轻微麻木 → 7-8分 → 3-14天 → 夜间痛醒 | 大小便异常 | 老人/基础病背痛伴发热应偏保守 | 骨科 |
| 皮疹 | 局部少量 → 没有 → 没有 → 无明显异常 → 成年人 | 快速扩散 → 轻微瘙痒 → 新药 → 水疱/疼痛 → 成年人 | 口唇肿胀 | 儿童皮疹伴发热应偏保守 | 皮肤科 |
| 呕吐 | 1-2次 → 可以 → 无明显异常 → 没有 → 成年人 | 6次以上 → 少量可以 → 发热 → 尿量减少 → 成年人 | 无法进水 | 儿童/老人呕吐应偏保守 | 消化内科 |
| 鼻塞 | 少于3天 → 没有 → 清水样 → 无明显异常 → 成年人 | 超过14天 → 轻微影响睡眠 → 黄绿色 → 面部疼痛 → 成年人 | 明显呼吸困难 | 儿童/老人鼻塞伴高热应偏保守 | 耳鼻喉科 |
| 咽痛 | 轻微疼痛 → 没有 → 没有 → 少于3天 → 成年人 | 吞咽明显痛 → 声音嘶哑 → 高热 → 3-7天 → 成年人 | 无法吞咽口水 | 儿童/老人咽痛伴高热应偏保守 | 耳鼻喉科 |

| 尿痛 | 没有血尿 → 没有发热腰痛 → 轻微尿频 → 少于24小时 → 成年人 | 颜色偏深 → 发热 → 尿频尿急明显 → 1-3天 → 成年人 | 明显血尿 | 孕产妇尿痛应偏保守 | 泌尿外科 |
| 月经异常 | 比平时少 → 轻微腹痛 → 不可能怀孕 → 少于24小时 → 无全身影响 | 明显增多 → 明显腹痛 → 可能怀孕 → 1-3天 → 头晕乏力 | 大量出血/浸透很快 | 已孕且出血/腹痛应红线 | 妇科 |
| 眼红 | 没有视力变化 → 轻微异物感 → 没有隐形/外伤 → 少于24小时 → 成年人 | 轻微模糊 → 眼痛畏光 → 戴隐形眼镜 → 1-3天 → 成年人 | 明显视力下降 | 儿童/老人眼红伴痛应偏保守 | 眼科 |
| 乏力 | 劳累后明显 → 没有胸闷气短 → 没有全身信号 → 少于3天 → 成年人 | 慢慢出现 → 活动后气短 → 体重下降 → 超过14天 → 成年人 | 胸痛/呼吸困难 | 老人/基础病乏力应偏保守 | 全科 |
| 心慌 | 没有胸痛气短 → 没有晕厥 → 偶尔漏跳 → 少于5分钟 → 成年人 | 轻微胸闷 → 头晕 → 持续很快 → 超过30分钟 → 成年人 | 晕倒过 | 老人/基础病心慌应偏保守 | 心内科 |
| 失眠 | 少于1周 → 轻微困倦 → 没有情绪风险 → 没有身体伴随 → 成年人 | 超过1个月 → 无法正常生活 → 明显低落 → 夜间憋醒 → 成年人 | 有伤害自己想法 | 老人/基础病失眠应偏保守 | 精神心理科 |
| 关节痛 | 没有外伤 → 没有红肿热痛 → 可以负重 → 少于24小时 → 成年人 | 运动后疼痛 → 明显肿胀发热 → 明显受限 → 3-14天 → 成年人 | 无法负重 | 老人/基础病关节痛应偏保守 | 骨科 |

## 边界测试

| 编号 | 输入/操作 | 预期 |
|---|---|---|
| B-01 | 不选症状，直接输入“胸痛半小时，伴随呼吸困难” | 识别胸痛并触发红线预警，说明触发原因 |
| B-02 | 不选症状，输入“最近有点不舒服” | 提示未识别明确主要症状 |
| B-03 | 任一症状选择红线项 | 直接进入红线预警页，无继续自查按钮 |
| B-04 | 完成一次普通自查后进入历史页 | 历史记录出现本次症状、日期、风险等级、科室 |
| B-05 | 点击“仍然不确定”反馈 | 出现“已记录”提示，并写入本地反馈事件 |
| B-06 | 结果页点击准备清单、问题清单、转诊单 | 都能进入对应页面并返回结果页 |
